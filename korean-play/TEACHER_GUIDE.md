# 담당 교사 안내

## 아이디와 기록

학생은 영문 소문자·숫자 4~20자의 아이디, 8~128자의 비밀번호로 가입합니다. 실명을 아이디로 쓰지 않도록 안내하세요. 아이디는 인증 서비스 내부에서 `아이디@students.malnori.invalid` 형식으로 변환되며, 이 주소는 이메일 수신용이 아닙니다. 학생의 실제 이메일은 수집하지 않습니다.

게임을 끝내면 종류·정답 수·점수·서버 완료 시각을 계정에 저장합니다. 최근 100판을 표시하고 전체 게임 수·정답 수·최고 점수를 집계합니다. 예전 브라우저 로컬 기록은 사용자 귀속을 확인할 수 없어 자동으로 계정에 가져오지 않습니다.

## 비밀번호 분실

화면에는 “비밀번호를 잊으셨다면 담당 교사에게 문의해 주세요”가 표시됩니다. 교사는 아이디와 학생 본인을 확인한 뒤 인증 관리 권한으로 새 비밀번호를 설정해야 합니다. 비밀번호 원문 조회는 제공하지 않습니다. 실제 이메일이 없으므로 이메일 재설정 링크는 사용할 수 없습니다.

필요하면 관리자 전용 로컬 도구 `scripts/teacher-reset-password.cjs`를 사용하세요. Supabase 프로젝트의 서버 전용 secret/service_role 키를 교사의 안전한 실행 환경에 `SUPABASE_SECRET_KEY`로 직접 설정하고, `node scripts/teacher-reset-password.cjs 학생아이디`를 실행합니다. 키나 새 비밀번호를 채팅·저장소·학생 기기·프런트엔드에 넣지 마세요. 도구는 비밀번호를 터미널에 표시하지 않으며 입력한 학생 한 명만 변경합니다. 이 도구를 웹 API로 공개하지 마세요.

공용 PC에서는 사용 후 로그아웃하도록 안내하세요. 학습 기록은 연습용 피드백이며, 클라이언트에서 제공한 정답 수를 저장하므로 부정행위 방지 시험 성적으로 사용하지 마세요.
