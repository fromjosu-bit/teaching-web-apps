# 말놀이

흑백 편집 디자인의 로컬 전용 국어 미니게임입니다.

## 실행

이 폴더에서 `npm start` 또는 `node server.cjs`를 실행한 뒤 http://127.0.0.1:4173 으로 접속하세요. 서버 종료는 터미널에서 Ctrl+C입니다. 별도 패키지 설치가 필요 없습니다.

`index.html`을 브라우저에서 직접 열어도 게임을 플레이할 수 있습니다. 기록 저장 방식은 브라우저와 파일 열기 정책에 따라 다를 수 있으므로 로컬 서버 실행을 권장합니다.

## 구성

- 맞춤법, 띄어쓰기, 어휘, 속담 게임별 6개 문항 중 무작위 5문제
- 오늘의 도전: 첫 맞춤법 문제와 무작위 혼합 4문제
- 정답과 해설, 점수와 결과 복습
- 게임 분류 필터, 브라우저에 최대 100판 기록 저장 및 삭제
- 키보드 1~3으로 답 선택, Esc로 팝업 닫기
- 모바일 대응, 외부 폰트·라이브러리·네트워크 요청 없음

`npm test`로 문항 데이터 구조를 검증할 수 있습니다. 서버는 127.0.0.1에만 연결되며, 공개 배포나 외부 서비스 등록을 하지 않습니다.

문서의 색상 토큰을 기준으로 #070708 / #ffffff / #808080을 적용했습니다. 사용자 정의 폰트가 제공되지 않아 시스템 고딕·명조로 대체했습니다.
